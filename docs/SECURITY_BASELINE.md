# Lost-Found 安全基线

## 已实现的应用层控制

- Spring Security 无状态 JWT 认证和方法级权限校验。
- CORS 仅允许本地 portal、admin 来源，不使用通配符来源。
- 帖子、评论、认领、私信、举报和上传接口具备 Redis 限流。
- 帖子、图片和分类输入在服务层重新校验，不能信任前端字段。
- 图片按真实文件内容识别格式，并限制大小、数量和 SHA-256 重复。
- MyBatis 使用参数绑定；Druid Wall 在失物招领 profile 中禁止多语句执行。
- 关键帖子、认领、治理操作写入业务审计事件。
- Swagger 和 Druid 匿名入口在 `lostfound` profile 中关闭。
- 上传文件访问限制在规范目录内，并检查规范化后的路径。
- 数据库、Redis、JWT 和 Druid 凭据使用环境变量占位符，不写入版本库。

## 威胁边界

SQL 注入防护是应用和数据库访问层控制，不能替代依赖升级、最小权限账号和数据库网络隔离。

DDoS 防护不能由本地 Spring Boot 代码完成。生产部署必须在应用前增加 CDN、云 WAF、负载均衡或云厂商 DDoS 防护，并配置：

- 连接数和请求速率限制。
- 登录、注册、上传和举报接口的更严格规则。
- IP、账号和设备维度的异常检测。
- 大文件上传限制和独立对象存储配额。
- WAF 规则、告警、封禁和应急扩容流程。

## 生产前必须完成

1. 将数据库用户名、密码、JWT 密钥和上传目录迁移到环境变量或密钥管理系统，不把生产凭据提交到仓库。
2. 创建只拥有 `ry-vue-lostfound` 必要权限的数据库账号，禁止使用 root 运行应用。
3. 使用 HTTPS，并在反向代理终止 TLS 后配置安全 Cookie、可信来源和 HSTS。
4. 将 CORS 来源改成实际 portal/admin 域名，删除 localhost 来源。
5. 关闭开发日志中的 SQL 参数明文输出，保留必要的审计事件。
6. 执行备份恢复演练，并验证上传文件和数据库可以成对恢复。
7. 对登录、发布、上传、评论、认领和举报执行压力及滥用测试。

本地环境中的限流、安全头和输入校验不能被描述为已经完成生产级 WAF 或 DDoS 防护。
